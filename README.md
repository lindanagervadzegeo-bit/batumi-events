# ბათუმის ივენთები — ზაფხული 2026

ავტომატურად განახლებადი ივენთების საიტი ბათუმისთვის.

## ფაილების სტრუქტურა

- `index.html` — თავად საიტი (კითხულობს `events.json`-ს)
- `events.json` — **ეს ფაილი აჩვენებს საიტი.** გენერირდება ავტომატურად.
- `manual_events.json` — ხელით დამატებული ივენთები (tkt.ge, batumievents.com და სხვა)
- `infobatumi_events.json` — ავტომატურად სქრეიპილი infobatumi.ge-დან
- `scrape_infobatumi.py` — სქრეიპერი infobatumi.ge-სთვის
- `merge_events.py` — აერთიანებს ორივე წყაროს → `events.json`
- `.github/workflows/update-events.yml` — ავტომატური, ყოველდღიური გაშვება

## ეტაპობრივი გეგმა (Setup — ერთხელ გასაკეთებელი)

### 1. GitHub რეპოზიტორის შექმნა
1. გახსენი [github.com](https://github.com), შედი ან დარეგისტრირდი
2. "New repository" → დაარქვი სახელი (მაგ. `batumi-events`)
3. ატვირთე ეს ყველა ფაილი (მათ შორის `.github` საქაღალდე) რეპოზიტორში
   - უმარტივესი გზა: repo გვერდზე "Add file" → "Upload files" → ჩააგდე ყველა ფაილი

### 2. Netlify-ს დაკავშირება GitHub-თან (ერთხელ გასაკეთებელი)
1. Netlify-ს დეშბორდზე: "Add new site" → **"Import an existing project"** (არა Drag & Drop)
2. აირჩიე "Deploy with GitHub" და მიეცი წვდომა შენს ახალ რეპოზიტორზე
3. Build settings ცარიელი დატოვე (არაფრის აშენება არ სჭირდება — უბრალო HTML-ია)
4. Deploy — ამის შემდეგ Netlify **ავტომატურად** გადაიდეპლოის ყოველ ჯერზე, როცა GitHub-ზე რამე შეიცვლება

### 3. მოწმდება, რომ ავტომატიზაცია მუშაობს
1. GitHub რეპოზიტორში → "Actions" ტაბი
2. უნდა ჩანდეს "Update Batumi Events" workflow
3. შეგიძლია ხელით გაუშვა ("Run workflow" ღილაკი), რომ დაუყოვნებლივ ნახო შედეგი
4. თუ სქრეიპერი წარმატებით იმუშავებს, `events.json` განახლდება, GitHub-ზე ავტომატურად დაკომიტდება, და Netlify ავტომატურად გადაიდეპლოის ახალ ვერსიას — შენი ხელით ჩართულობის გარეშე

## რჩევა სქრეიპერის შესახებ

(იხილე ინსტრუქცია ფაილის თავში). სანამ ეს არ გადაამოწმო და არ დაარეგულირო, სქრეიპერმა შეიძლება
